# 💼 Telegram-бот: Менеджер проектов (Портфолио)

Telegram-бот для хранения и управления вашими проектами. Позволяет сохранять ссылки, описания, статусы разработки, стек технологий (навыки) и прикреплять скриншоты к каждому проекту.

## ✨ Возможности

* **Управление проектами:** добавление, просмотр карточек, редактирование любых полей и удаление проектов.
* **Медиа и детали:** прикрепление скриншотов (сохраняются локально) и подробных описаний.
* **Стек технологий и статусы:** привязка навыков к проектам и управление общими справочниками навыков и статусов.
* **Быстрый поиск:** достаточно отправить название проекта в чат, чтобы открыть его карточку.

## 🛠 Стек технологий

* **Python 3**
* **pyTelegramBotAPI** (`telebot`) — взаимодействие с Telegram Bot API
* **SQLite3** — локальная база данных

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd <папка_проекта>
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Создайте файл `config.py`** в корне проекта и укажите токен вашего бота (получить можно у [@BotFather](https://t.me)) и имя файла базы данных:
   ```python
   TOKEN = "ваш_токен_от_BotFather"
   DATABASE = "projects.db"
   ```

4. **Запустите бота:**
   ```bash
   python main.py
   ```
   *(При первом запуске таблицы в БД и базовые списки навыков/статусов создадутся автоматически).*

## 📋 Список команд

### Основные команды
* `/start` — запуск бота и приветствие
* `/info` — справка по всем доступным командам
* `/new_project` — создать новый проект
* `/projects` — список всех проектов (с кнопками для открытия карточек)
* `/add_description` — добавить или изменить описание проекта
* `/add_photo` — прикрепить скриншот к проекту
* `/skills` — привязать навык к проекту
* `/update_projects` — изменить данные существующего проекта
* `/delete` — удалить проект

### Управление справочниками
* `/add_skill` — добавить новый навык в общий список
* `/update_skill` — переименовать навык
* `/add_status` — добавить новый статус в общий список
* `/update_status` — переименовать статус
