# 🤖 Бот-портфолио (Portfolio Bot)

Telegram-бот на Python для удобного создания, хранения и управления личным портфолио проектов. Позволяет структурировать информацию о разработках в базе данных, отслеживать их статусы и быстро делиться ссылками на репозитории.

## ✨ Основные возможности
* **Добавление проектов:** сохранение названия, подробного описания, ссылки на GitHub и текущего статуса разработки.
* **Просмотр портфолио:** удобный вывод списка всех добавленных проектов и детальной информации по каждому из них.
* **Редактирование и удаление:** быстрое обновление данных (например, смена статуса или добавление ссылки) и удаление неактуальных записей.
* **Работа с таблицами БД:** автоматическое создание и управление структурой таблиц для хранения информации о проектах, статусах и навыках.

## 🛠 Стек технологий
* **Язык программирования:** Python 3.x
* **Библиотека для Telegram API:** pyTelegramBotAPI (telebot) *(или aiogram — укажи свою)*
* **База данных:** SQLite3

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd ТВОЙ_РЕПОЗИТОРИЙ
   ```

2. **Установите необходимые зависимости:**
   ```bash
   pip install pyTelegramBotAPI
   ```

3. **Настройте конфигурацию:**
   Создайте файл `config.py` (или `.env`) в корневой папке и добавьте туда токен вашего бота:
   ```python
   TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
   ```

4. **Запустите бота:**
   ```bash
   python main.py
   ```

## 📋 Доступные команды
* `/start` — приветствие и краткая инструкция по работе с ботом
* `/new_project` — добавить новый проект в портфолио
* `/projects` — посмотреть список всех проектов
* `/update_projects` — изменить данные существующего проекта
* `/delete` — удалить проект из базы данных
