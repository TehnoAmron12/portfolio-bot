# 💼 Portfolio Bot — Telegram-бот для хранения портфолио

Небольшой и удобный Telegram-бот на Python, который помогает держать все свои проекты в одном месте. Больше не нужно вспоминать, куда закинул ссылку на репозиторий или скриншот старого пет-проекта — всё сохраняется в базу данных и открывается в пару кликов прямо в мессенджере.

## Что умеет бот

- **Вести список проектов:** добавление названия, ссылки (на GitHub или сайт), подробного описания и текущего статуса разработки.
- **Прикреплять скриншоты:** можно загрузить фото проекта — бот сохранит файл на диск, привяжет его к карточке и будет отправлять вместе с описанием.
- **Отмечать стек технологий:** к каждому проекту легко привязать использованные языки, фреймворки или библиотеки.
- **Быстро показывать карточки:** достаточно выбрать проект из списка кнопок или просто написать его название в чат.
- **Гибко настраивать базу:** прямо из Telegram можно добавлять новые навыки и статусы в общий справочник или переименовывать старые.

## Команды бота

**Основные:**
- `/start` — запуск бота и приветствие
- `/info` — подробная справка по всем доступным командам
- `/new_project` — пошаговое добавление нового проекта
- `/projects` — просмотр всех сохранённых проектов и их карточек
- `/add_description` — добавить или обновить описание проекта
- `/add_photo` — загрузить скриншот или обложку для проекта
- `/skills` — привязать навык к выбранному проекту
- `/update_projects` — отредактировать любое поле проекта (имя, описание, ссылку, статус или фото)
- `/delete` — удалить проект из базы

**Управление справочниками БД:**
- `/add_skill` и `/update_skill` — добавить новый навык в базу или переименовать существующий
- `/add_status` и `/update_status` — добавить новый статус в базу или изменить название старого
